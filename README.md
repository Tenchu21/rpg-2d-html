# Dungeon of Ember

Jogo 2D de RPG em HTML, CSS e JavaScript.

## Como jogar

- Abra o arquivo `index.html` no navegador, ou
- publique no GitHub Pages para jogar online.

## Controles

- WASD / Setas: mover
- Espaço: atacar
- E: interagir

## Objetivo

- Fale com Mira
- Derrote os slimes
- Coleta os cristais
- Receba a recompensa
